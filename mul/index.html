🧺곱셈은 "똑같은 묶음"이에요

사탕을 3개씩 4봉지 담으면? 3+3+3+3 = 12개! 이걸 짧게 쓰면 3 × 4 = 12 랍니다.

줄을 누르면 구구단을 읽어 줘요!

🗺️구구단 보물지도

칸에 손을 올리면 가로·세로 길이 보여요. 칸을 누르면 네모 그림으로 바뀐답니다.

✨외우기 쉬워지는 비법

전부 81개 같지만, 사실 진짜로 외울 건 얼마 안 돼요!

🔁 뒤집어도 똑같아요

3×4 와 4×3 은 답이 같아요 (둘 다 12). 그래서 외울 양이 거의 절반으로 줄어요!

5️⃣ 5단은 끝이 0, 5

5, 10, 15, 20, 25… 끝자리가 5 → 0 → 5 → 0 으로 반복돼요. 시계 보기와 똑같아요.

2️⃣ 2·4·6·8단은 짝수만

답이 모두 짝수예요. 2단은 "둘씩 뛰어 세기", 4단은 2단을 두 번 더한 것!

9️⃣ 9단 손가락 마술

손가락 10개를 펴고, 곱하는 수만큼 센 손가락을 접어요. 접은 손가락 왼쪽 = 십의 자리, 오른쪽 = 일의 자리!

💪 어려운 건 딱 5개

6×7=42, 6×8=48, 7×8=56, 7×9=63, 8×9=72. 아이들이 가장 많이 틀려요. 여기만 집중!
